# DameChamba MVP

MVP web 

Stack principal:

- React 18
- Vite 5
- React Router 6
- Tailwind CSS
- Lucide React

## Requisitos

- Node.js 18+
- npm 9+

## Instalacion

```bash
npm install
```

## Ejecucion en desarrollo

```bash
npm run dev
```

La app queda disponible (por defecto) en:

- `http://localhost:5173`

## Build de produccion

```bash
npm run build
```

## Vista previa del build

```bash
npm run preview
```
## Scripts disponibles

- `npm run dev`: inicia servidor de desarrollo.
- `npm run build`: genera build optimizado.
- `npm run preview`: sirve el build localmente.
